Sistema de Cadastro de Alunos

Este projeto é um programa simples desenvolvido em Python para cadastrar, consultar e excluir alunos pelo terminal. Os nomes são armazenados em uma lista durante a execução do programa.

Funcionalidades

Cadastrar um aluno;

Organizar os nomes em ordem alfabética;

Consultar os alunos com numeração;

Excluir um aluno cadastrado;

Encerrar o programa;

Como funciona

Ao iniciar o programa, o usuário encontra o seguinte menu:

1 - Cadastrar aluno
2 - Consultar alunos
3 - Excluir aluno
4 - Sair

Na opção 1, o programa solicita o nome do aluno, aplica a primeira letra maiúscula e adiciona o nome à lista.

Na opção 2, os nomes cadastrados são organizados em ordem alfabética e exibidos com uma numeração.

Na opção 3, o programa mostra a lista e solicita o número do aluno que será excluído. Se o número for válido, o cadastro é removido e uma mensagem de confirmação é exibida.

Na opção 4, o programa é encerrado. Caso seja informada uma opção diferente, a mensagem Opção inválida! será exibida.

Tecnologias utilizadas

Python;

Terminal ou prompt de comando;

Editor de código, como Visual Studio Code.

Como executar

Instale o Python 3 no computador.

Salve o código em um arquivo com a extensão .py, por exemplo, cadastro_alunos.py.

Abra o terminal na pasta em que o arquivo foi salvo.

Observação

Os dados permanecem apenas enquanto o programa está aberto. Ao encerrá-lo, os nomes cadastrados são apagados, pois ainda não há integração com arquivo ou banco de dados.

Salvar os dados em um arquivo ou banco de dados.
