Sistema de Cadastro de Alunos

Programa de terminal desenvolvido em Python para praticar as quatro operações básicas de um cadastro: cadastrar, consultar, atualizar e excluir alunos.

Funcionalidades

Cadastrar alunos e impedir nomes duplicados;

Consultar os alunos em ordem alfabética;

Mostrar a quantidade total de alunos cadastrados;

Atualizar o nome de um aluno;

Excluir um aluno da lista;

Validar nomes vazios, números inválidos e opções inexistentes;

Encerrar o programa com uma mensagem de confirmação.

Menu do programa

==========================================
       SISTEMA DE CADASTRO DE ALUNOS
==========================================
1 - Cadastrar aluno
2 - Consultar alunos
3 - Atualizar aluno
4 - Excluir aluno
5 - Sair

Para atualizar ou excluir um cadastro, o programa exibe a lista numerada. Basta informar o número correspondente ao aluno desejado.

Tecnologias utilizadas

Python 3;

Terminal, PowerShell ou Prompt de Comando;

Git e GitHub para versionamento.

Como executar

Instale o Python 3.

Clone este repositório:

git clone https://github.com/Tami4lvess/Prova-de-Versionamento.git

Entre na pasta do projeto:

cd Prova-de-Versionamento

Execute o programa:

python vsnmt.py

No Windows, caso o comando anterior não funcione, use py vsnmt.py.

Observação

Os dados ficam armazenados somente durante a execução. Ao fechar o programa, os cadastros são apagados, pois o projeto ainda não utiliza arquivo ou banco de dados.
